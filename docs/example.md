The `blueprint-config` package is a pure Python library that facilitates configuration of a Pyscript automation. Normally, Pyscript automations are configured using YAML derived from the `pyscript.app` section in `configuration.yaml`. This process is somewhat error prone and not particularly user friendly. The `blueprint-config` package facilitates this by generating a Home Automation Blueprint that generates a script that returns data that corresponds to the input selectors values in the blueprint.
